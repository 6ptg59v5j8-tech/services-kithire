DBAVL PRODUCT LAYOUT FIX — INSTALLATION

This update fixes the public equipment catalogue and individual product pages.
It does not change the database, equipment records, prices, uploaded image URLs,
Cloudflare bindings, admin login, or R2 storage.

FILES UPDATED
- public/styles.css
  Complete replacement. Removes fixed product image frames and cropping,
  adds intact bordered product cards, even grid spacing, and properly spaced
  buttons at desktop/tablet/mobile sizes.
- public/item.js
  Complete replacement. Displays the main uploaded product image at its
  natural aspect ratio and provides contained gallery thumbnails.
- public/item.html
  Complete replacement. Loads the updated product detail stylesheet/script.
- public/index.html
  Only the stylesheet URL has a version query added to force browsers to
  fetch the new CSS instead of using an old cached copy.

INSTALL
1. In your GitHub repository, open the public folder.
2. Replace public/styles.css with the styles.css from this package.
3. Replace public/item.js with the item.js from this package.
4. Replace public/item.html with the item.html from this package.
5. In public/index.html, replace the existing file with the supplied index.html,
   or simply change its stylesheet reference to:
   /styles.css?v=20261123-layoutfix
6. Commit the changes and let Cloudflare Pages deploy.
7. Hard refresh the public site after deployment (Cmd + Shift + R on Mac).

IMPORTANT
Do not run schema.sql or MIGRATION-OLDER-DBAVL.sql for this visual fix.
Do not delete or recreate D1 or R2. Existing products and uploaded images stay
where they are.
